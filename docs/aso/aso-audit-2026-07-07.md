## Reviews & downloads growth plan

**Reviews (target: 10+ reviews at ≥4.5★ within 3–4 weeks — count starts rendering, conversion jumps):**

1. In-app prompt already shipped (`mobile/src/bootstrap/reviewPrompt.ts`) — good gating. Weakness: Android happy path deep-links to the Play listing (user must find Rate → write). Consider calling the native In-App Review API at delight moments _without_ the sentiment pre-gate on Android (policy forbids sentiment-gating the native card; ungated = compliant and much lower friction). Keep sentiment modal for iOS.
2. Personally ask every real early user (friends, beta testers, Discord/community) — genuine reviews only; incentivized/fake reviews risk removal.
3. Reply to every review from Console (dev responses lift rating recovery and signal care).
4. Watch Android Vitals: crash >1.09% or ANR >0.47% suppresses ranking outright.

**Downloads (organic, £0):**

1. Metadata changes above = the core lever; expect indexing shifts in 1–3 weeks.
2. Referral program already in-app — surface it post-lesson-complete.
3. Content loop already built (43 public lessons + prerender): add Play badge/smart-banner deep links on garzoni.app lesson pages.
4. Reddit (r/UKPersonalFinance value-posts, no spam), TikTok/YouTube Shorts of lesson content, Product Hunt launch.
5. After ~1K installs: Store Listing Experiments (icon first, then screenshots) — 1 experiment at a time, 7+ days.
6. Promotional Content (LiveOps) in Console once eligible — 2× explore acquisitions for participating apps.

## UK/Europe focus (installs are currently Indian testers)

Play rankings, ratings display, and "similar apps" placement are **per-country storefront**. Indian tester installs build zero UK/EU visibility — and their ratings/reviews mostly display to Indian users. Consequences:

1. UK SERP presence starts from ~zero regardless of tester count. Metadata changes + UK installs are the only levers.
2. Every early UK/EU install is worth many tester installs: Play weights install velocity, retention, and review origin per storefront.
3. Get first UK reviews fast — UK storefront shows UK-region reviews first; 5–10 genuine UK reviews at 4.5★+ changes the listing's face for the target market.
4. UK channels (free): r/UKPersonalFinance & MoneySavingExpert forum (value posts only, no spam), UK personal-finance TikTok/Shorts, university money-skills societies (core demographic for gamified learning), LinkedIn UK fintech community.
5. EU expansion: RO listing first (content ready), then DE/ES/FR/IT listings when translations exist — each localized listing indexes in that storefront's keywords.
6. Point all £50 ad spend at UK only (see below) — do not let campaign default to worldwide, or budget drains to cheap non-target geos.

## £50 Google Ads plan

Reality: UK finance CPI ≈ £1.50–£3 → £50 buys ~20–35 installs. Value = velocity signal + search-term data, not scale.

- Campaign: **App campaign (installs)**, Google Ads → linked to Play.
- Geo: UK only (or £35 UK + £15 Romania if RO listing ships; RO CPI ≈ £0.15–£0.40 → +50–80 installs for velocity).
- Budget: £5/day × 10 days — one burst, not a trickle (algorithm needs ≥£5/day to learn).
- Bidding: Install volume (not target-CPI — no data yet, and tCPA needs conversions).
- Assets: 5 headlines from keyword clusters ("Learn money in 5 min a day", "Personal finance, gamified", "From first budget to first stock", "500+ bite-size money lessons", "Your AI money tutor"), 3–5 descriptions, all 8 screenshots + icon; add a 15–30s vertical video if quick to cut (ads ≠ store listing; video matters here).
- Measure: installs, retained day-1, and the search-terms report → feed winning terms back into listing keywords.
- Don't: run Search-network keyword campaigns with £50 (finance CPCs £2–6 = 10 clicks, nothing learned).
