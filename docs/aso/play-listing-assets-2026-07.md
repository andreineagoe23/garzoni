## 7. Screenshots — reuse iOS ones?

Short answer: **keep them for launch, re-frame later.** Content matters more
than device frame, and 8 caption-led screenshots beat 4 perfect ones.

But fix these when you iterate:

1. **Remove iPhone device frames / status bar.** Android users notice the Dynamic
   Island and iOS status bar — subtle "this isn't built for my phone" trust hit.
   Best pattern: frameless UI crop on a colored background with a big caption
   headline (what Finelo/Investmate do), so the same asset works on both stores.
2. **Dimensions:** Play accepts iOS portrait sizes (min 320px, max 3840px,
   within 16:9–9:16). 1290×2796 (iPhone 6.7") passes. No resize needed.
3. **First 3 do 90% of the work** — order: (1) value prop "Master money in 5
   min/day", (2) The Climb path, (3) real tools (Portfolio Analyzer).
4. **Feature graphic (1024×500) is Android-only** — iOS has no equivalent, so
   make sure it exists and shows the value prop + app UI, not just the logo.
   It's the header image for any featuring and shows in some placements.
